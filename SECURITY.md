# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's
**Security → Advisories → Report a vulnerability** flow. Do not open a public
issue, publish proof-of-concept exploits, or test against other users.

Include the affected URL or component, reproduction steps, impact, and any
suggested remediation. Remove private keys, wallet recovery material,
credentials, session cookies, personal data, and live access tokens from the
report.

## Safe-harbor testing

- Use accounts and wallets you control.
- Do not submit transactions, social-engineer users, degrade availability,
  scan unrelated infrastructure, or access data that is not yours.
- Stop and report immediately if testing exposes another user's data.

## Supported versions

Security fixes target the current `main` branch and production deployment.
Older commits and preview deployments are not supported.
